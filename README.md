# Телеграмм бот для личных нужд

#### Файлы репозитория:
- `/bot.py` - основной файл инициализации, сейчас в нём также содержится модуль односторонней синхронизации фотографий в телеграмм канале и канале в дискорде через вебхук.
- `/commands/` - папка, содержащие остальные модули, подлючаются непосредственно в `/bot.py`.

#### Модули бота
- `\music.py` - работает через личные сообщения с ботом. Отправляет трек, ссылка на который в Spotify отправлена после использования команды, в формате mp3.
- `\webmtomp4.py` - работает в указанном телеграмм-канале. Переделывает файл из .webm в .mp4, удаляет изначательное сообщение и отправляет новое с конвертированным файлом.
